# 🏆 Portfolio Requirement

Before graduation, every learner should have:

* 25+ GitHub repositories
* 10+ deployed applications
* 5+ full-stack projects
* 3+ production deployments
* 1 large-scale capstone system
* Technical documentation for every project
* Architecture diagrams for major systems
* CI/CD implementation experience
* Cloud deployment experience
* Team collaboration experience

The portfolio becomes the proof of engineering capability.
